---

## 🎮 How to Play

1. 🔤 Type any 5-letter word and press Enter
2. 🟩 Green — letter is correct and in the right spot
3. 🟨 Yellow — letter is in the word, but wrong spot
4. ⬜ Gray — letter isn't in the word at all
5. 🏁 Guess the word within 6 tries to win!

    Try 1/6: crane
    🟩 🟨 ⬜ ⬜ ⬜
    Try 2/6: brave
    🟩 🟩 🟩 ⬜ 🟨

## 🛠️ Customize It

- 🌍 Add more words — edit the WORDS list in wordle.py
- 🎯 Hard mode — reduce tries from 6 to 4
- 🔥 Win streak tracker — save results to a text file
- 💡 Hint system — reveal the first letter after 3 tries
